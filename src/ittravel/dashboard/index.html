Aegis: login risk scoring

Each login is scored by two gradient-boosting models trained on the RBA login dataset (31.3M logins, 4.3M users; Wiefling et al., 2022): one for account takeover, one for attack IPs. Features come from the user's own history: new country, network or device, a country hop within an hour, recent failures, and how busy the IP is. With coordinates, a physical impossible-travel check runs too. Every number on this page comes from the live API.
